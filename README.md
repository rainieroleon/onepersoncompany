# One Person Company — Skills & Prompts for Solo Service Businesses

This repository is a curated toolkit for building a solo-run service business: a structured business blueprint, prompts, and templates to help an entrepreneur design, launch, and operate a "one-person company." It is primarily a collection of documents (business blueprint and resources) rather than runnable code.

## What’s in this repo

- `One Person Company - Services Business Entrepreneur.md` — The core project: a comprehensive, step-by-step business blueprint covering idea generation, market research, prototyping, operations, launch, and growth. Intended to seed an "Obsidian/Second Brain" vault and to drive prompt-based AI skills.
- `rainiero.favorites_8_8_26.html` — Exported bookmarks (Favorites bar) saved as an HTML file. Contains links to AI tools, prompts, design resources, and other references.
- `README.md` — This file.

## Recommended usage

1. Clone the repository:

   git clone https://github.com/rainieroleon/onepersoncompany.git

2. Read the main blueprint:

   - Open `One Person Company - Services Business Entrepreneur.md` in your editor or in Markdown preview to review the full methodology, folder templates, and the RALPH-based persona questionnaire.

3. Import into your note system (optional):

   - The repo contains an "obsidian-ai-second-brain" vault architecture you can copy into Obsidian or any note-taking system as a starting workspace.
   - The questionnaire and project templates are organized to be moved into Projects/ and Areas/ within a PARA-based vault.

4. Use bookmarks and resources:

   - Open `rainiero.favorites_8_8_26.html` in a browser to restore or view the saved bookmarks for AI tools and references.

## Short checklist to get started

- Read the entrepreneur persona questionnaire and answer it — populate `Projects/01-Entrepreneur-Profile/` in your vault.
- Create a new Obsidian vault or folder and copy the folder structure from the blueprint to start building your Second Brain.
- Run small experiments: pick one productized service offering and create a 90‑day plan (see prompts in the blueprint).
